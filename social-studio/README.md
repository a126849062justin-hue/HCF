# HCF 社群貼文模板工作室 — Social Studio

HCF 鯊魚格鬥俱樂部專用的**社群媒體貼文產生器**。
填入文字 → 即時預覽 → 一鍵匯出 PNG，直接發 Instagram / Facebook。

風格沿用官網品牌：紅 `#C81015`、碳黑 `#111`、Oswald + Noto Serif/Sans TC。

## 內建模板

| 模板 | 尺寸 | 用途 |
|------|------|------|
| 課程宣傳 | 1080×1080（1:1） | 體驗班、課程招生 |
| 選手聚焦 | 1080×1350（4:5） | 介紹館內選手 / 教練 |
| 賽事公告 | 1080×1080（1:1） | 出賽、賽事結果 |
| 每週課表 | 1080×1350（4:5） | 一週課程表 |
| 金句語錄 | 1080×1080（1:1） | 勵志金句、教練語錄 |
| 限時動態 | 1080×1920（9:16） | IG / FB Story |

## 使用方式

1. 直接用瀏覽器開啟 `index.html`（不需安裝任何套件）。
2. 上方分頁切換模板，左側填寫文字，右側即時預覽。
3. 可選擇上傳一張背景圖（人物照 / 訓練照），不傳則用碳黑底。
4. 按 **匯出 PNG** 下載圖片。

### 小技巧

- 在標題 / 行動呼籲欄位用大括號把字標紅，例如 `新手{體驗班}`。
- 換行直接按 Enter（副標、標題都支援多行）。
- 課表每行格式為 `星期 | 課程 | 時間`，用 `|` 分隔。

## 技術說明

- 純前端、零相依：HTML + CSS + 原生 JavaScript。
- 匯出使用 [html2canvas](https://html2canvas.hertzfeld.dev/)（CDN 載入）。
- Logo 取用上層的 `../shark_logo.png`，若放到他處請自行調整路徑。
